# Lib Directory

This directory contains core utility libraries, API clients, and shared helpers.

## Files
- `api.ts`: Axios instance pre-configured with auth request/response interceptors.
- `utils.ts`: General helper utilities (such as `cn` class merger).
- `indexed-db-storage.ts`: Promise-based IndexedDB storage helper for client-side caching.
- `auth.ts`: NextAuth configuration options and provider setup.
- `validation.ts`: Zod schemas and validation types.
